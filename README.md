# PIXEL PLAY — THAI WORD CHALLENGE

## ต้องติดตั้ง
- Node.js 18 หรือใหม่กว่า
- อินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจ Node.js

## เปิดเว็บไซต์บนเครื่อง
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ PIXEL_PLAY ใน Terminal / Command Prompt
3. รัน `npm install`
4. รัน `npm start`
5. เปิดเบราว์เซอร์ที่ `http://localhost:3000`

## สิ่งที่ทำงานได้ในเวอร์ชันเริ่มต้น
- หน้าเว็บไซต์ขาว-ดำแบบ Minimal
- แสดงพยัญชนะสุ่มขนาดใหญ่ด้วย HTML (ไม่ใช้ canvas เพื่อป้องกันจอดำ/ขนาดผิดพลาด)
- สุ่มพยัญชนะไทย
- ช่องกรอกคำตอบ 8 หมวดหมู่
- จับเวลา 60 วินาที
- ตรวจรูปแบบตัวอักษรเบื้องต้น
- เก็บคะแนนสูงสุดใน LocalStorage
- สร้างห้องและเข้าร่วมห้องออนไลน์ผ่าน Socket.IO

## หมายเหตุสำคัญ
- การตรวจความหมายด้วย AI ยังไม่เปิดใช้จนกว่าจะกำหนด AI provider ฝั่งเซิร์ฟเวอร์
- ตั้งค่าตัวแปรสภาพแวดล้อม `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` ก่อนเรียก `/api/validate`
- ห้ามใส่ API key ในไฟล์ JavaScript ฝั่งหน้าเว็บ
- ระบบห้องออนไลน์ในรุ่นนี้เป็นโครงสร้างสร้าง/เข้าร่วมห้องและแสดงรายชื่อ ยังไม่ใช่ระบบแข่งขันพร้อมซิงก์รอบ/คำตอบ/คะแนนแบบเรียลไทม์
- การตรวจในหน้าเกมปัจจุบันตรวจเฉพาะว่าคำขึ้นต้นด้วยพยัญชนะที่สุ่ม ไม่ได้ยืนยันความหมายหรือหมวดหมู่

## โครงสร้าง
- `index.html` หน้าแรกและหน้าจอเกม
- `css/style.css` รูปแบบเว็บไซต์
- `js/app.js` ระบบหน้าเว็บและ Phaser
- `server/index.js` Express, Socket.IO และ API ตรวจคำตอบ AI


## หน้าสรุปผล
- แสดงจำนวนคำตอบถูก/ผิดและคะแนน
- แสดงคำตอบที่ผู้เล่นกรอกและตัวอย่างเฉลย
- ช่องว่าง คำขึ้นต้นผิด หรือคำตอบที่ AI ยืนยันไม่ได้ จะถูกนับเป็นผิด
- ต้องตั้งค่า AI_API_KEY, AI_BASE_URL, AI_MODEL เพื่อให้ตรวจความหมายจริง


## ระบบตรวจคำตอบแบบผสม (Hybrid)
1. ตรวจพยัญชนะต้นก่อน
2. ค้นหาคำตรงตัวใน `server/dictionary.json` ก่อน (มี 5 หมวดหมู่)
3. ถ้าไม่พบในฐานข้อมูล จะส่งไปให้ AI ตรวจต่อเมื่อกำหนด `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` บนเซิร์ฟเวอร์
4. ถ้าไม่มี AI หรือ AI ตรวจไม่ได้ ระบบนับเป็นคำตอบผิดและแจ้งเหตุผลอย่างตรงไปตรงมา
5. เพิ่มคำศัพท์ได้โดยแก้ไข `server/dictionary.json` แล้ว restart เซิร์ฟเวอร์

### ตั้งค่า AI (ทางเลือก)
- คัดลอก `.env.example` เป็น `.env` และใส่ค่าจากผู้ให้บริการ AI ที่รองรับ OpenAI-compatible Chat Completions
- ต้องติดตั้งตัวโหลด environment เช่น `npm install dotenv` และเพิ่ม `require("dotenv").config();` เป็นบรรทัดแรกของ `server/index.js` หรือกำหนด environment variables ใน Windows ก่อนรัน `npm start`
- ห้ามแชร์ไฟล์ `.env` หรือ API key กับผู้อื่น
- หากยังไม่ตั้งค่า AI ระบบฐานข้อมูลยังใช้งานได้ตามปกติ
- ตรวจสถานะได้ที่ `http://localhost:3000/api/status`


## คำเฉลยเมื่อไม่พบคำตอบ
เมื่อคำตอบไม่ผ่าน ระบบจะค้นหาคำตัวอย่างที่ตรงกับตัวอักษรและหมวดหมู่จาก `server/dictionary.json` แล้วแสดงเป็นคำเฉลยในหน้าสรุปผล หากไม่มีคำในฐานข้อมูลสำหรับตัวอักษรนั้น ระบบจะแจ้งว่าไม่มีคำเฉลยตัวอย่างในฐานข้อมูล

## V8: หมวดหมู่ปรับตามตัวอักษร
- เมื่อสุ่มตัวอักษร ระบบจะตรวจว่าหมวดของใช้ภายในบ้านมีคำที่ขึ้นต้นด้วยตัวนั้นหรือไม่
- หากไม่มี จะเปลี่ยนหมวดแรกเป็น "ของใช้ในชีวิตประจำวัน" โดยอัตโนมัติ
- อีก 4 หมวดยังคงเป็นของกิน ของใช้ส่วนตัว สัตว์ และอาชีพ
- ชื่อหมวดที่เปลี่ยนจะถูกส่งไปตรวจคำตอบและแสดงในหน้าสรุปผลด้วย
- เพิ่ม endpoint `GET /api/round/:letter` สำหรับเลือกหมวดตามตัวอักษร


## V9: รับประกันคำเฉลยครบ 5 หมวด
- ระบบตรวจคำในหมวดหลักทั้ง 5 ก่อน
- หากหมวดหลักไม่มีคำขึ้นต้นด้วยตัวอักษรนั้น จะเลือกหมวดสำรองที่มีคำจริงจากฐานข้อมูล
- หมวดสำรองประกอบด้วย ของใช้ในชีวิตประจำวัน, พืช, สถานที่, ธรรมชาติ และคำทั่วไป
- ระบบไม่ใช้หมวดซ้ำในรอบเดียวกัน
- API ส่งคำเฉลยตัวอย่างของแต่ละหมวดมาพร้อมข้อมูลรอบเกม
- หากผู้เล่นเว้นช่องว่าง หน้าสรุปผลยังแสดงคำเฉลยที่ระบบเลือกไว้
- ระบบจะไม่เริ่มรอบที่จัดหมวดหมู่ได้ไม่ครบ 5 ข้อ
